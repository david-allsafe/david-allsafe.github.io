~$ cat summary.txt

Final report for the Digital Forensics course: a comparative memory forensics study of two malware families with very different behavior, RedLine Stealer (infostealer) and LockBit 4.0 (ransomware), both captured in an isolated environment.

Main conclusion: the forensic footprint depends on the malware family and on when the capture happens relative to the process lifecycle. A process that is still running (RedLine) leaves very different traces from one that has already exited (LockBit, "encrypt-and-exit" behavior).

~$ cat case-a-redline.log

Case A (RedLine Stealer): captured with the process still running (PID 1040).

  1. 1. Acquisition: WinPmem; resolved a PTE Remapping mode issue by forcing the PhysicalMemory target
  2. 2. Code injection (T1055): 4 RWX regions identified via windows.malfind
  3. 3. Network: 2 TCP sockets in CLOSED state, meaning an unsuccessful C2 attempt
  4. 4. Persistence: none established; .NET binary
  5. 5. Attribution: MalwareBazaar (16 detections, 16 YARA rules) plus CLR loading confirmed in memory

~$ cat case-b-lockbit.log

Case B (LockBit 4.0, sample LockBitGreen4.0-rc-577 from MalwareBazaar): process already terminated at capture time.

  1. 1. Acquisition: WinPmem and FTK Imager both failed due to unrecognized driver signature (Driver Signature Enforcement); bypassed with Magnet DumpIt
  2. 2. Process state: already terminated at capture time ("encrypt-and-exit" behavior)
  3. 3. Impact: files and the sample itself encrypted (unique hexadecimal extension); ransom note Restore-My-Files.txt
  4. 4. Anti-forensics: shadow-copy deletion confirmed on the live system (T1490)
  5. 5. Absences: no code injection and no persistence visible in the dump
  6. 6. Attribution: strings in physical memory (version, personal ID, access key) matching the ransom note

~$ cat conclusion.txt

Both cases confirm that conclusion: the same tools (Volatility 3 and Sysinternals) gave opposite evidence depending on the malware family and the timing of the capture. One case shows code injection and active networking; the other shows completed encryption and an already terminated process.
